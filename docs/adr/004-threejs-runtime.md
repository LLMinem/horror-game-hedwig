# ADR-004: Continue with Three.js for the full game

**Status:** Accepted direction. **Retrospectively documented:** 2026-10-22.

Continue building the full game with Three.js. This is the current runtime direction, not merely a temporary environment viewer and not a permanent engine commitment. Reassess Unreal Engine or another engine only when actual resource scale, visual quality, performance or gameplay needs provide a reason. The project's age and inherited choices alone establish neither a need for a rewrite nor a duty to preserve every implementation detail.

No engine migration, comparison project or preparatory abstraction follows from keeping that option open. Work against the current runtime and bring concrete evidence to any future reassessment.

**Supported history:** [The recorded direction on 2026-10-18](https://github.com/LLMinem/horror-game-hedwig/commit/6b49925dfb05d8d7bc97ed2979d1fe07ea59da67) explicitly covers the full game and evidence-triggered reassessment. It does not establish when Three.js was originally selected or which alternatives were considered then.
